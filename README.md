Lattice lets you run WebGPU/JS code natively - using Deno, WGPU, OpenXR and Vulkan!

### Run on Desktop

cargo run --release

### Run with WebXR/OpenXR

cargo run --release -- --xr


Lattice is a WIP, to do :

- WebXR examples
- Audio
- WebRTC
- Ergonomics etc
- Steam Frame Builds

Supported:
- Linux Desktop + OpenXR
- Windows Desktop + OpenXR
- Quest OpenXR
- Computer Shaders
